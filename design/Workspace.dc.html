Auth Flow

Every request from the desktop client passes through the gateway before it touches a service. Tokens are minted once and cached locally — the storage layer is covered in adapter-design.md.

Token exchange
fn exchange(code: &str) -> Result<Token> {
    let req = TokenRequest::new(code)
        .with_pkce(verifier);
    gateway.post("/oauth/token", req) // single mint
}

Session state lives in TokenStore (sled tree auth/v2) and is rebuilt on launch.
